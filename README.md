# Silsila

Silsila is an interactive family memory archive that transforms personal stories into connected constellations, timelines, and migration maps.

Users can add or record family memories, identify important people, places, and dates, and explore how different stories connect across generations.

## Features

* Add written or recorded family memories
* Interactive memory constellation
* Timeline view
* Migration map view
* People, place, and date extraction
* Search across saved memories
* Confidence scores and correction controls
* Local browser storage
* Responsive design

## Built With

* HTML
* CSS
* JavaScript
* Web Speech API
* Local Storage

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/silsila.git
```

Navigate to the project folder:

```bash
cd silsila
```

Start a local server:

```bash
python -m http.server 8000
```

Open the project in your browser:

```text
http://localhost:8000
```

You can also open `index.html` directly, but microphone permissions may work better through a local server.
